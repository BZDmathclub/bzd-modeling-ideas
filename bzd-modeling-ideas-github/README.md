# BZD Modeling Ideas

`bzd-modeling-ideas` 是一个面向数学建模竞赛的整体求解思路生成 Skill，支持 Codex 与 Claude Code。

用户提供完整赛题及附件后，Skill 会先从全题角度重建问题之间的数据流、模型依赖和结果传递关系，再针对每一问生成多种可行建模方案，比较模型的适用条件、优势、局限和验证方法，并给出推荐模型及选用理由。

本项目基于2020—2025年16道高教社杯全国大学生数学建模竞赛题目的赛题、评分细则、评分要点、评阅概述及完整评阅流程进行归纳和蒸馏，重点强化建模论文的完整性、整体性、跨问题联动和模型选型逻辑。

该 Skill 不会简单罗列模型名称，也不会虚构数据、参数或计算结果，而是帮助使用者建立一套能够贯穿全文、可以实际编程实现并具有验证闭环的求解路线。

## 主要功能

- 从整道赛题出发梳理统一的建模主线；
- 分析各问题之间的输入、输出和依赖关系；
- 生成跨问题联动流程图；
- 统一全文的变量、符号、单位、约束和评价指标；
- 针对每一问说明任务、已知条件、目标结果及数学本质；
- 为每一问提供至少两种真正不同的可行模型；
- 使用表格比较模型的假设、步骤、优势、风险和适用场景；
- 给出推荐模型、选用理由、备用模型及替换条件；
- 提供可以实际实现和对照验证的创新方向；
- 设计多模型公平比较、灵敏度分析和稳健性检验；
- 检查漏题、断链、数据泄漏和前后口径不一致。

## 输入

使用者应尽量提供：

- 完整数学建模赛题；
- 所有问题及子问题；
- 附件说明、数据字典、图表和补充规则；
- 实际附件数据；
- 可选的 `bzd-problem-translator` 题意翻译报告。

## 输出

Skill 默认生成一份 Markdown 建模思路报告，包含：

1. 整题建模主线；
2. 跨问题联动链；
3. 全文统一建模口径；
4. 分问题求解思路；
5. 推荐的全文技术路线；
6. 多模型对比与验证设计；
7. 论文落地清单；
8. 完整性与断链检查。

每一个问题按照以下顺序展开：

1. 问题概述；
2. 总体求解思路；
3. 可用模型及选型比较；
4. 推荐模型与选用理由；
5. 备选模型及适用条件；
6. 多模型公平比较建议；
7. 创新与改进方向。

## 安装

### Codex

将完整文件夹复制到：

```text
Windows：%USERPROFILE%\.codex\skills\bzd-modeling-ideas
macOS/Linux：~/.codex/skills/bzd-modeling-ideas
```

### Claude Code

项目级安装：

```text
项目目录/.claude/skills/bzd-modeling-ideas
```

用户级安装：

```text
~/.claude/skills/bzd-modeling-ideas
```

## 调用示例

```text
使用 $bzd-modeling-ideas 分析以下完整数学建模赛题：

赛题：C:\赛题\2025年国赛C题.pdf
附件：C:\赛题\附件.xlsx

请输出贯穿全文的整体建模思路，并针对每一问列出多个可行模型，
说明推荐模型的选用理由、备用条件、创新方向和验证方法。
```

## 重要说明

本项目根据历史赛题及评阅材料总结可迁移的建模规律和常见失分风险，不代表全国大学生数学建模竞赛官方评审标准，也不保证任何具体奖项。

Skill 提供的是建模思路、模型选择和验证框架。具体参数、数值结果、最优方案和模型性能必须根据使用者提供的实际附件数据计算。

禁止在缺少数据的情况下虚构计算结果、模型精度、最优参数或官方推荐方法。
